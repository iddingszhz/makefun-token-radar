Launch Radar ranks pre-token DeFi protocols by the implied value of a future token launch, worked out from a sealed DefiLlama snapshot, and shows each protocol's farm plan in a static dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
